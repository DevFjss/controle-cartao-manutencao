Configuração única no Supabase para o botão “Limpar Supabase” funcionar

O Supabase bloqueia exclusões feitas pela chave pública enquanto não houver permissão. Rode uma vez o SQL abaixo em SQL Editor do Supabase (Opção A é a mais segura e é a que o painel tenta usar primeiro).
